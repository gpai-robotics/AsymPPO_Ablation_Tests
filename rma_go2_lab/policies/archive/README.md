# Policy Archive

This directory contains frozen policies and deployment bundles from inactive
C1, adaptation, teacher/student, and baseline attempts.

These files are retained for comparison and future research. They are not
compatible by default with the active AsymPPO launchers because observation
layouts, model classes, action contracts, and deployment configuration may
differ.

The only active bundle is:

```text

```
