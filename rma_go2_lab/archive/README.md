# Source Attempt Archive

This directory preserves inactive locomotion implementations:

- `adaptation`: adaptation and RMA-style experiments
- `blind_c1`: C1 blind-policy model code and related variants
- `teacher_student`: privileged teacher/student and imitation experiments
- `old_variants`: superseded environment and model variants

Nothing here is imported or registered by the active package. Archive paths
may contain historical imports that only become valid after restoring their
complete dependency set.

The active implementation remains under `rma_go2_lab/envs`,
`rma_go2_lab/models/asymppo`, and `rma_go2_lab/models/teacher`.
